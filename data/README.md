# Data

The saved generations and the run files are distributed as two ZIP archives attached to the
[v1.0 release](https://github.com/kikibasic/GenQER/releases/tag/v1.0) of this repository
(they are too large to keep in the repository itself). Unzip both archives in this folder:

```text
data/
  generations/   <- genqer-generations-v1.0.zip  (17 MB, 73 files)
  runs/          <- genqer-runs-v1.0.zip         (61 MB, 250 files)
```

Dataset codes: `covid` = TREC-COVID, `nfc` = NFCorpus, `scifact` = SciFact, `dl19` / `dl20` =
TREC DL 2019 / 2020, `news` = TREC-NEWS, `robust04` = Robust04. Strategy names are those of the
paper: `legacy`, `strict`, `aspect`, `hybrid`, `broaden`, `corpus_strict`, `corpus_aspect`,
`corpus_broaden`.

The archives contain only text generated by the LLM, lists of corpus terms, and document
identifiers. Queries, documents and relevance judgments are not redistributed; the scripts load
them through Pyserini.

## generations/

One JSON file per dataset and strategy.

| Folder | Content |
|---|---|
| `main/{dataset}_{strategy}.json` | the five main datasets, eight strategies, five passages per query |
| `heldout/{dataset}_{strategy}.json` | TREC-NEWS and Robust04, eight strategies, five passages per query |
| `count_control/{dataset}_strict_40.json` | strict extended to 40 passages per query for the passage-count control; the first five are identical to `main/` |
| `variability/trial{2,3}/{dataset}_{strategy}.json` | two further independent generations of legacy, strict and aspect on DL19 and DL20 (trial 1 is `main/`) |

```json
{
  "meta": {"dataset": "dl19", "strategy": "aspect", "name_in_experiment_code": "strict_v2",
           "model": "gpt-4o", "snapshot": "gpt-4o-2024-08-06", "temperature": 0.7,
           "created_at": "...", "updated_at": "..."},
  "generations": {"<query id>": ["passage 1", "passage 2", "..."]},
  "aspects":     {"<query id>": [{"aspect_label": "...", "focus": "...", "distinguishing_angle": "..."}]},
  "probe_terms": {"<query id>": ["term", "..."]}
}
```

- `aspects` (aspect, hybrid, corpus_aspect): the Stage 1 decomposition. hybrid has four aspects;
  its first passage is generated with the strict prompt and has no aspect.
- `probe_terms` (corpus_strict, corpus_aspect, corpus_broaden): the up to 25 terms taken from
  the top 10 documents of the initial BM25 retrieval and inserted into the prompt.
- NFCorpus files hold all 323 BEIR test queries. The paper evaluates 308 of them (see the main
  README); in `count_control/nfc_strict_40.json` the 15 excluded queries keep five passages.

## runs/

TREC format (`qid Q0 docid rank score tag`), top 100 documents after reranking; the score is
the cosine similarity of the reranker. The `tag` column holds the internal name of the
experiment code and can be ignored.

| Folder | Content |
|---|---|
| `main/{dataset}_{name}.run` | seven datasets; `name` = `no_expansion`, one of the eight strategies, or `all8` (all-strategy integration) |
| `count_control/{dataset}_{condition}.run` | `single_strict_{10,20,40}`, `pool_{5,10,20}_{seed}`, `mix_{2,4}_5_0` (Table IV) |
| `stage/{dataset}_bm25-strict_rerank-all8.run`, `..._bm25-all8_rerank-strict.run` | the two mixed conditions of the stage-wise analysis (Fig. 1) |
| `bge/{dataset}_{strict,all8}.run` | reranking with `bge-base-en-v1.5` |
| `subsets/{dataset}_{config}.run` | strategy subsets for per-dataset selection: `all6`, `drop_X` (all but X), and the greedy pairs and triples; short codes as in `../results/README.md` |

For NFCorpus, `main/nfc_no_expansion.run` has 308 queries (BM25 returns nothing for the other
15); the single-strategy runs have all 323.

`python scripts/evaluate_runs.py --check` re-evaluates every run file and compares it with the
per-query values in `../results/per_query/`.
